# 旅程档案公开浏览版

这个目录可直接部署到 GitHub Pages。页面提供 25 条单日旅程、行动形状库和叙事关注对象总表的只读浏览与检索。

数据来自本地旅程数据库的一次导出快照；网站上的修改不会写回数据库。更新本地数据后，在原工作目录运行 `04_旅程浏览器/导出公开浏览版.py`，再提交更新后的文件。

其中 22 条案例整理自公开的第一人称旅行记叙，3 条家庭案例是资料约束的模拟，页面分别标明性质。行动的时间精度、来源性质和不确定性以各案例页面为准。关注对象占比依据本库行动时间轴的文字估算，不代表游玩时长或原始游记全文的篇幅。

部署方法：在 GitHub 仓库的 **Settings → Pages** 选择 **Deploy from a branch**，发布 `main` 分支的根目录。
